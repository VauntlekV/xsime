# 犀术IME / 犀術IME / XSIME 1.2.0

状态：五端源码已合并 main，正式标签 `v1.2.0` 冻结于 `c09ff55e19c4eebb29ecc06148ed32b15bb8fd5f`。[GitHub Release](https://github.com/scholay/xsime/releases/tag/v1.2.0) 已公开四端安装包、iOS 社区未签名 IPA、校验和与四端更新清单。iOS 1.2.0（67）已完成 Apple 处理并提交外部 TestFlight 与 App Review；截至 2026-10-28 00:01 JST，分别为 `WAITING_FOR_BETA_REVIEW` / `WAITING_FOR_REVIEW`，商店仍提供 1.1.9。

产品构建、自动回归和安装验收均在远端 CI 执行。维护者本机只处理归档、签名与发布资料，未运行产品构建、测试或安装；原开发工作区、备份和验收资料保留。

## 更新内容

- iOS / Android：个人 AI 助手预设、提示词编辑和快捷入口管理；输入方案与官方插件采用卡片视图。正交键盘独立于并击插件，选择 isaac2026 后使用自然码并击。
- 移动端：完善空格选词与光标手势、双指开合 Buffer、空格捏合导入当前输入框；长按发送一秒发送全部剩余内容，最后一块发送后收起 Buffer。保留私人输入框和跨输入目标保护。
- macOS / Windows / Linux：设置首页集中展示产品信息、联系链接和完整的多语言 README、许可文本；打字练习支持 EPUB 素材、书籍/文章侧栏、段落与双轨格子视图，成绩归入打字练习。评分仍使用原来的正文和文章身份，移除素材不会清除已保存成绩。
- Windows：纳入 PR #279 的候选分页、组字起点定位、Buffer 设置与异步准备状态、富剪贴板保留、Capsule 交互、截图缩略图及用户学习词库维护修复。
- Linux：内置方案可在设置中选择，组字未结束时延后切换；完善候选矩阵分页与窗口隐藏收尾。安装包移除精确 Python 包名绑定，版本化引擎依赖改为私有随包运行库，同一 DEB 的 Ubuntu 24.04 / 26.04 验证由 CI 执行。
- 快捷键：Windows / Linux 的应用默认组合统一为 Alt+Shift+原功能键；三桌面端 Capsule 改为 C（macOS ⌘⇧C，Windows / Linux Alt+Shift+C）。保留已保存的个人快捷键。

词库与短语的新增功能继续暂缓。既有导入方案、用户词库、历史记录和配置均纳入保留范围。
