## 发布顺序

1. 提交并推送官方插件，锁定本体引用；本体和插件均保留原始作者。
2. 完成逐端对齐，在集成 PR 上运行远端检查，修复失败后合并 main。
3. 冻结同一 main 提交与插件 pin，构建四端正式包及社区 IPA。
4. 沿用已授权的签名、Android 长期密钥和 Apple 账号；发布前验证实际凭据和权限。
5. iOS 归档上传后分别读回处理、TestFlight 分发和 App Review 状态。GitHub 发布和商店生效分别记录；如协调同批公开，商店使用审核后手动发布。
6. 匿名读回公开资产、校验和及更新清单，再记录最终结果。
